Ce dépôt Git contient les supports et le matériel pédagogique du cours « Méthodes d’analyse des données en grandes dimensions et apprentissage automatique pour la mécanique », dispensé dans le cadre du Master 2 Mécanique, commun aux parcours Solides et Fluides, accrédité par l’Université Paris-Est Créteil (UPEC) et l’Université Gustave Eiffel.
